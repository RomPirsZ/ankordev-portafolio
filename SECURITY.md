# Política de seguridad

Si encuentras una vulnerabilidad en https://ankordev-portafolio.vercel.app o en este repositorio, repórtala de forma privada desde [Report a vulnerability](https://github.com/RomPirsZ/ankordev-portafolio/security/advisories/new). Por favor, no abras un issue público.

Incluye la URL o el archivo afectado, los pasos para reproducirla y el impacto que tiene.

**Fuera de alcance:** denegación de servicio, ingeniería social, pruebas automatizadas masivas y hallazgos sin impacto demostrable (por ejemplo, cabeceras que no aplican a un sitio estático).

## English

To report a vulnerability in the site or this repository, please use [private vulnerability reporting](https://github.com/RomPirsZ/ankordev-portafolio/security/advisories/new) instead of a public issue. Include the affected URL or file, steps to reproduce and the impact.
